# 战斗模型口径与可证实范围

来源：[AKEDatabase《终末地数据机制导论》](https://github.com/NagiYume/AKEDatabase/blob/main/public/CH/research/终末地数据机制导论.md)第1、4部分；固定表请以当前任务核对的[AKEData](https://www.akedata.wiki/)版本为准。社区研究本身承认部分机制可能不精确，不能替代实测。

常驻攻击力：`[(干员基础攻击+武器基础攻击)×(1+攻击百分比)+固定攻击]×[1+floor(主能力)×0.005+floor(副能力)×0.002]`。基础和装备固定值在转换前保留原始小数，仅主副能力换算时取整数。暴击期望乘区为`1+暴击率×暴伤`，伤害还要按元素/技能类别、目标防御与抗性等分别处理。基础暴击率5%、暴伤50%只是无其他修改时的研究基线；特性与状态会改变它们。

技力上限300、战斗自然回复约8/秒是研究基线；具体战技费用、重击回技力、连携回能、终结能量与冷却必须读取技能。脚本包含声明模型的`initialSp=200`、回能比例和暂停等默认值，不能称游戏对所有场景的确定事实。不同干员的独占帧不等于全队操作锁；长姿态的尾段不应让所有后续动作串行等待。只有经过来源核对的占用规则才允许并行。

随skill分发的重放引擎是`endfield-tactics-lab`的**通用部分覆盖快照**：带来源的直接命中、常驻属性、标准资源事件、周期伤害/增益基础框架。公开版不附干员专属规则、游戏原始数据或图片。异常反应、召唤物、复杂破防、动态武器/套装、状态消耗和很多连携条件尚未完整解释。原项目`1.6.4@11262943-8`时仅46/132类动作有自动直接命中profile；这个比例不是完整角色覆盖率，也不代表之后版本。输出应列缺口、标已建模直伤，禁止称“游戏真实总DPS”。

同一个操作可能有技能释放、命中、增益起止、姿态/后台命中多个事件。循环必须核对SP、返还池、终结能量、CD、锁、增益和专属状态；重复轮末状态不闭合时，不可报告持续DPS已验证。助手应先解释第一个资源或条件失败点，再描述其后的影响。
