# ENDFIELD

面向《明日方舟：终末地》玩家的独立战斗研究 skill：[`skills/endfield-combat`](skills/endfield-combat/SKILL.md)。

安装：将 `skills/endfield-combat` 整个文件夹复制到自己的 Codex `skills` 目录，然后调用 `$endfield-combat`。所需 Node.js 24+；本地重放命令和输入格式见[说明](skills/endfield-combat/references/replay-input.md)。

这个公开包只提供离线的通用计算与来源核对指引。它不包含游戏客户端素材、原始游戏表、图片、参考EXE、账号登录或游戏中的浮窗/自动操作。实际角色计算需由使用者的助手取得并核对同版本来源数据。专属机制覆盖尚不完整，输出会标明缺口，不能称为全角色实战总DPS或全局最优轴。
