# 终末地战斗轴实验室 · Endfield Combat Lab

面向《明日方舟：终末地》玩家与攻略研究者的**离线战斗轴重放工具及智能体说明**。仓库当前发布的是 [`endfield-combat` 技能包](skills/endfield-combat/SKILL.md)：它帮助解释队伍操作顺序，并在数据齐备时计算**声明模型内的**资源账本和直接命中伤害。名称中的“实验室”强调计算结果需要来源和实战复核。

## 目前能做什么

| 功能 | 当前范围 |
| --- | --- |
| 阅读和讨论战斗轴 | 将重击、战技、连携技、终结技放在同一时间轴中分析；普通攻击只作为重击前置链的一部分，不单独列卡。 |
| 重放资源与时序 | 按输入的队伍、养成、技能和操作轴，输出动作、事件及逐轮账本，检查已声明的技力、能量、冷却和循环边界。 |
| 计算已建模伤害 | 提供**同版本且已核对来源**的数值包与命中事件包后，计算模型内直接命中 DPS；缺包或机制未知时明确列出缺口。 |
| 保留证据边界 | 输出数据包 SHA-256、版本、状态、警告及未覆盖机制；拒绝混用不同版本数据。 |

本公开包**不附带角色专属机制适配器或游戏数值包**，也不提供自动寻找全局最优轴的生成器。`modeled` 和 `resourceFeasible` 只说明声明模型的重放结果；报告的 `certification` 始终为 `unverified`，不能据此认定真实游戏中的完整 DPS、可持续循环或最优打法。

## 两种使用方式

### 直接作为本地命令行工具

只需 **Node.js 24+**。下载本仓库后运行：

```text
node skills/endfield-combat/scripts/run-axis.mjs <输入JSON> [输出JSON]
```

省略输出路径时，报告写入终端。输入包括数据版本、队伍、轴的阶段与动作；要计算伤害，还须提供同版本的数值包和命中事件包。字段解释及状态含义见[本地重放输入说明](skills/endfield-combat/references/replay-input.md)。普通玩家不需要手写 JSON；任何兼容的前端、脚本或智能体都可以准备输入并调用这个命令。仓库目前没有内置图形界面或自动数据抓取。

### 交给智能体协助分析

[`SKILL.md`](skills/endfield-combat/SKILL.md) 是开放的 Markdown 工作说明，可供能够读取本地文件、运行 Node.js 的智能体使用。把 `skills/endfield-combat` 文件夹放在该智能体支持的技能目录，或直接把 `SKILL.md` 路径提供给它；**不要求使用 Codex，也不要求复制到 Codex 专属目录**。不同产品的自动发现与调用方式可能不同。智能体负责核对可访问的数据来源、组织输入并解释输出，但不能把推测当作实战验证。

## 数据和输出应如何理解

工具本身不登录游戏、不读取玩家账号。若要重放真实角色，需要从合法可访问来源取得对应版本的角色、武器、装备、技能和敌人条件，并核对后转换为输入包。可参考 [AKEData](https://www.akedata.wiki/) 与[森空岛攻略目录](https://wiki.skland.com/endfield/catalog?mainTypeId=2&subTypeId=11&header=0)；社区攻略可提供候选打法，不能代替数值与时序验证。战斗模型的研究口径和已知限制见[战斗模型](skills/endfield-combat/references/combat-model.md)。

报告中 `incomplete` 表示数据或规则不足，`invalid` 表示声明动作不可执行，`modeled` 表示声明事件可以重放。即使得到数值，未覆盖的连携条件、动态增益、特殊资源、后台命中等仍可能改变真实结果。比较打法时，应保持版本、队伍养成、敌人和循环时长一致，并检查逐事件及逐轮账本。

## 使用边界与验证

本仓库只分发离线的通用计算代码和说明，不包含游戏客户端素材、原始游戏表、图片、参考程序、账号登录、画面采集、游戏内浮窗或自动操作。请遵守[《明日方舟：终末地》官方公平游戏声明](https://endfield.hypergryph.com/news/5907)；本仓库不代表官方认可。

运行随包测试：

```text
node skills/endfield-combat/tests/smoke.mjs
```

测试覆盖合成输入的独立运行、缺口披露和版本不匹配拒绝，**不是**真实队伍的实战验收。
